# Video Recommendation Service (AI-Driven Adaptive Content Delivery)

Flask API that ranks lesson videos for a student's weak area using the trained
KNN model (`models/best_model.pkl`) and returns the top 3. Structured to match
the sibling `ml-services/meal-planning/` service (same layout: `app.py`,
`requirements.txt`, `models/`, `.gitignore`).

## What the model actually does

`models/best_model.pkl` is a `KNeighborsClassifier`. It does **not** output
videos. It classifies a *single video's* 5 features into a suitability class
(`High` / `Medium` / `Low`). Feature order is fixed by `models/scaler.pkl`:

```
weak_area_encoded, difficulty_encoded,
content_quality_score, student_suitability_score, duration_minutes
```

`/recommend` filters `videos.csv` to the requested weak area, scores every
candidate with the model, and ranks by P(High).

## ⚠️ `videos.csv` is SAMPLE data

The real video catalog was not available, so `videos.csv` here is placeholder
data generated by `generate_sample_videos.py` (72 rows, real topic names +
difficulties, made-up titles, no real YouTube ids). Replace it with the real
catalog — same columns — and the frontend embeds will light up automatically
(fill the `youtube_id` column).

## ⚠️ Requires Python 3.12

The pickles were created with **scikit-learn 1.6.1 / numpy 1.26.4**, which have
no wheels for Python 3.13+. Use Python 3.12. `requirements.txt` pins the exact
versions (unlike `meal-planning`, which doesn't need to). `best_model.pkl` is a
joblib dump, so `app.py` loads all artifacts with `joblib` (which also reads
the plain-pickle encoders).

## Run

```bash
cd ml-services/video-recommendation
py -3.12 -m venv venv
venv\Scripts\python.exe -m pip install -r requirements.txt
venv\Scripts\python.exe app.py
```

Runs on **port 5002** (meal-planning uses 5001, quiz/Next.js uses 3000/3001).

Health check: `GET http://127.0.0.1:5002/` (or `/health`, `/api/health`) → JSON.
Recommend: `POST http://127.0.0.1:5002/recommend` with `{"weak_area": "Addition"}`.

The Next.js app proxies this through `src/app/api/video-recommendation/recommend/route.ts`
(same pattern as `src/app/api/meal-plan/generate/route.ts`), configurable via the
`VIDEO_RECOMMENDATION_SERVICE_URL` env var (defaults to `http://127.0.0.1:5002`).
