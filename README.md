Project Descritpion: 
AI-Driven School Management System with Real-Time Monitoring is an intelligent platform designed to improve school management and student learning processes using AI technologies. The system supports real-time monitoring of student reading improvement, weak detecting , adaptive learning and meal and nutrition. It helps teachers and administrators make better decisions through automated analysis and smart recommendations, while providing students with a more personalized and effective learning experience.
